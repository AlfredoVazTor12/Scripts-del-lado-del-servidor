De Estático a Dinámico

La transición de la Web 1.0 (solo lectura) a la Web 2.0 (interactiva) marcó un hito crucial. La introducción de JavaScript permitió crear experiencias más ricas.

Etapas Clave

Etapa Características Años (Aprox.)
Web 1.0 Páginas estáticas, contenido de solo lectura. 1991 - 2004
Web 2.0 Interactividad, redes sociales, contenido generado por el usuario. 2004 - 2010
Web 3.0 Web semántica, IA, descentralización. 2010 - Actualidad
La evolución continúa hacia experiencias más inmersivas.
